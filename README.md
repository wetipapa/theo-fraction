# 분수 쓱싹

튀어 오르는 음식 중에서 문제에 맞는 분수만 골라 베는 6~9세용 분수 게임.
WTPP PLAY의 다섯 번째 서비스다.

## 어떻게 노는가

1. 화면 위에 분수가 하나 뜬다 (예: 1/2)
2. 아래에서 피자·수박·초콜릿 같은 것들이 튀어 오른다. 저마다 다르게 칠해져 있다
3. 문제와 같은 만큼 칠해진 것만 손가락으로 그어 벤다
4. 한 획에 여러 개를 베면 점수가 배로 오른다
5. 다른 그림이나 폭탄을 베면 하트가 줄어든다. 놓친 것에는 벌점이 없다
6. 끝나면 최고 점수가 남고, 기록을 사진 한 장으로 저장할 수 있다

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 빌드
npm test           # 단위 테스트
npm run lint       # oxlint
```

## 구조

```
src/
├─ config/gameConfig.ts   난이도·규칙·물리·분모 목록. 숫자를 고칠 일은 대부분 여기
├─ data/foods.ts          분수를 담는 음식들 (모양·색)
├─ lib/
│  ├─ fraction.ts         분수 계산. 소수로 바꾸지 않고 정수 곱으로만 비교한다
│  ├─ problems.ts         문제 생성과 정답 판정 ← 게임을 늘릴 때 손대는 곳
│  ├─ swipe.ts            스와이프 자취와 선분-원 충돌
│  ├─ engine.ts           게임 한 판의 상태. 0~1 좌표로만 계산한다
│  ├─ shapes.ts           분수를 그림으로 그린다 (Canvas)
│  ├─ render.ts           한 프레임 그리기. 0~1 좌표를 픽셀로 바꾸는 유일한 곳
│  ├─ feedback.ts         Web Audio 효과음과 진동
│  └─ storage.ts          최고 점수·설정 (이 기기 안에만 남는다)
├─ components/            버튼, 분수 표시, 링크
└─ screens/               첫 화면 · 게임 · 결과
```

설계 배경과 확장 방법은 `CLAUDE.md`에 적어 두었다.
